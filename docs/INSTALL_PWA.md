# Panduan Instalasi Aplikasi PWA SENTRA ANGLER (Android & iPhone)

SENTRA ANGLER dibangun sebagai **Progressive Web App (PWA)** sehingga dapat di-install ke layar utama HP tanpa melalui Play Store atau App Store.

---

## A. Instalasi di HP Android (Google Chrome / Edge)

1. Buka alamat aplikasi SENTRA ANGLER menggunakan browser **Google Chrome**.
2. Login menggunakan akun Bendahara atau Anggota.
3. Ketuk tombol **"Install App"** yang muncul di sidebar/header aplikasi, **ATAU**:
   - Ketuk ikon titik tiga (`⋮`) di pojok kanan atas Chrome.
   - Pilih **"Tambahkan ke Layar Utama"** / **"Install app"**.
   - Konfirmasi dengan menekan **Install**.
4. Ikon **SENTRA ANGLER** akan muncul di beranda HP Anda dan berjalan dalam mode layar penuh seperti aplikasi native.

---

## B. Instalasi di iPhone / iPad (Safari)

1. Buka alamat aplikasi SENTRA ANGLER menggunakan browser **Safari** (wajib Safari di iOS).
2. Ketuk ikon **Share** (kotak dengan panah ke atas) di bilah navigasi bawah Safari.
3. Gulir ke bawah lalu pilih **"Add to Home Screen"** (*Tambahkan ke Layar Utama*).
4. Pastikan nama tertulis `SentraAngler`, lalu ketuk **Add** di pojok kanan atas.
5. Buka aplikasi langsung dari ikon di layar utama iPhone Anda.

---

## C. Mode Offline & Sinkronisasi

- Saat koneksi internet terputus, aplikasi akan menampilkan indikator **"Mode Offline — Data Cache Sementara"**.
- Data terakhir yang sudah dimuat tetap dapat dilihat sebagai referensi sementara.
- Pencatatan transaksi baru dinonaktifkan sementara saat offline agar tidak ada catatan yang dianggap tersimpan sebelum benar-benar tersinkronisasi ke server/database.
